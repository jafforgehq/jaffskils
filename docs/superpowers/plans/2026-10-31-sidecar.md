# sidecar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A mod that docks a live pane beside the chat with the jaffskils logo, session facts, subagents, skills, MCP servers, tool activity, files and todos.

**Architecture:** One hooks module (`register.tsx`) collects data from engine events into `$.state` atoms and draws the `Pane` from them; one surface module (`motion.tsx`) animates the logo shimmer, spinners and the working dot on its own frame clock. No other plugin is needed.

**Tech Stack:** Claude Code mod API (`claude-code`, `claude-code/testing`), TypeScript/TSX, `claude plugin test` / `claude plugin validate`.

**Spec:** `docs/superpowers/specs/2026-10-31-sidecar-design.md`

API reference while working: the types file the `plugin-authoring` skill names when it loads (grep it for `'skill.prompt'`, `AgentInfo`, `SessionContextBreakdown`, `ClientProps`, `MockClock`), and its `examples/pane.tsx`, `examples/pane.test.tsx`. Follow `plugins/session-recap/` for layout and style.

## Global Constraints

- Plugin `sidecar` in `plugins/sidecar/`; `plugin.json` has `name`, `description`, `"author": { "name": "jafforgehq" }`, `"types": "./types/index.d.ts"`, and **no `version`**.
- Pane id `sidecar`, pane title `sidecar`, slash command `sidecar`; every atom uses `plugin: 'sidecar'` and a `shape` tag.
- Colours: theme keys only (`claude`, `success`, `error`, `warning`, `dimColor`), except the logo gradient `#D97757` → `#9B7BFF` and shimmer `#FFF4E6`.
- Logo exactly:
  ```
   █ ▄▀█ █▀▀ █▀▀ █▀ █▄▀ █ █   █▀
  ▄█ █▀█ █▀  █▀  ▄█ █ █ █ █▄▄ ▄█
  ```
  and `◆ jaffskils` below 32 body columns.
- Timings: shimmer about 1500 ms; spinner frames `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` at 80 ms; flash 2000 ms; finished agents listed 180000 ms; agent poll 1000 ms while any agent is `pending`, `running` or `waiting`; elapsed refresh 30000 ms.
- Context bar: `success` < 50 %, `warning` < 80 %, `error` ≥ 80 %; width `max(4, bodyColumns - 10)`.
- Commit messages end with the two attribution lines from the session (`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and the `Claude-Session:` line).

## Review Focus

1. A session before its first turn: `cost`, `context.percent` and `breakdown` absent. Expect `—` in their place, never `NaN`, `$undefined` or a thrown render (test in Task 3).
2. A tiny pane (16 columns, 10 rows). Expect every section header, no negative-width bar, nothing wrapped into extra rows (tests in Task 5).
3. A long or multi-line Bash command. Expect its first line only, cut with `…` to the pane width (test in Task 2).
4. A server the project disabled (`disabledMcpServers`). Expect it neither under `✓` nor under `✗` (test in Task 3).
5. The same skill used twice. Expect one `used` row, moved to the top with the newer time (test in Task 2).

### Task 5: Colour, motion and fitting the rows

**Files:**
- Create: `plugins/sidecar/hooks/motion.tsx`
- Modify: `plugins/sidecar/hooks/register.tsx`
- Test: `plugins/sidecar/hooks/register.test.tsx`

**Interfaces:**
- Consumes: every section's `Line[]`, atoms `shimmer`, `isWorking`, `tick`.
- Produces in `motion.tsx`: a default `ClientModule<MotionProps>` with `type MotionProps = { kind: 'logo'; rows: [string, string]; colors: string[]; shimmer: number } | { kind: 'spinner'; color: string } | { kind: 'pulse'; color: string }`. The logo sweeps a 3-column `#FFF4E6` band across over about 1500 ms each time `shimmer` differs from the value in its local state, then stops its `every`. Spinner cycles the frames at 80 ms; pulse alternates `●` bold and dim while mounted.
- Produces in `register.tsx`: `function fitRows(lines: Line[], rows: number): Line[]` (drop non-header lines from the last section backwards until it fits; if headers alone still do not fit, swap the logo for `◆ jaffskils`, then cut from the end).
